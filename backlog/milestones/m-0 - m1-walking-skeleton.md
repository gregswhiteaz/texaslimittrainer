## Description

Thinnest end-to-end path: toolchain + CI; seeded rules engine and headless playtest runner with invariant checks; 6-max preflop chart and basic postflop equity advice with grading; TAG bots built on it; launch to Home, New game opens a default 6-max $4/$8 cash table vs TAG bots in the browser; play a hand with legal actions and see the result; a basic Hand Review panel lists the user's decisions with recommendation and grade.
